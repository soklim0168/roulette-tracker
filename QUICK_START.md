# Run the browser app

Open `app.html` directly in any modern browser. No Python, installation, or server is required.

You can also use GitHub Pages:

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose `main` and `/ (root)`, then save.
4. GitHub will show the published link after deployment finishes.

The app stores data in browser local storage. It is a tracking and statistical screening tool, not a way to predict roulette outcomes.
